## 1. 做了什么

| 部分 | 内容 |
|---|---|
| 幂级数 | 常点处的幂级数解，全部步骤：设级数、逐项求导、代入并平移指标（写出平移前的指标 k）、合并 tⁿ 的系数（起点不同时前几个 n 单独写）、递推公式（分子分母分解成一次因式）、精确分数的系数、按 a₀、a₁ 拆成两个基本解（加右端带来的部分）、证明了才说「是多项式」、定理保证的收敛半径（下界）、代入所选初值 |
| 奇点 | 判断正则 / 非正则，写出指标方程；正则奇点、齐次方程、指标根为有理数时展开 Frobenius 级数（大根总能展开；小根在差不是整数、或差为整数但递推留出自由系数时展开）；需要对数项时如实说不展开；收敛到最近的另一个奇点 |
| 解的公式 | 常系数方程拆成 u = u_h + u_p：特征方程、判别式（精确判定三种情况）、特征根（无理时保留 √ 并附小数）、齐次解及其走向、弹簧振子的阻尼说法、待定系数法的试探解（共振时乘 t^s 并说明）、由初值定常数（能精确就精确）、最终的解、稳态 / 暂态、与数值解的核对 |
| 拖动 | 面板的展开点、最高次数、初值都有滑块；原有的参数滑块同样驱动面板，推导和图实时重算 |
| 图 | 级数：部分和（虚线）与同一初值的数值解（实线）、保证收敛的阴影带；公式：u（实线）、u_h（虚线）、u_p（点线） |
| 预设 | 新的一章「幂级数与解的公式」7 个：Airy、Legendre（l 滑块）、Hermite（m 滑块）、dy/dt = 2ty、受迫阻尼振子（b、w 滑块）、dy/dt = −k·y + 1（k 滑块）、x'' + w²·x = cos t（w 滑块） |
| 链接 | `ser`（ps / sol）、`sn`、`sc`、`si` |
| Claude | 两个只返回文字的新工具 `power_series`、`solution_formula`；和面板同一个计算、同一套中英文措辞；widget 没变（仍 `z-1`），**不需要**删除连接器重加 |
| 帮助 / 首页 / 更新说明 | 帮助页「表单」一节新增面板说明；首页「能做什么」加一条，「限制」里那句「不给出封闭形式的解」改为准确的说法；更新说明新增一条 |

## 2. 实测（浏览器）

第一轮实测用的是 `next dev --webpack`，评审修复之后在生产构建（`next build` + `next start`）上又看了一遍：Frobenius 题目的链接 `m=second&eq=t*x''+x'+t*x=0&ser=ps` 直接打开，面板给出 Frobenius 级数，「复制链接」可用；受迫振子 x'' + 3x' + 2x = cos t 的解的公式 x = (3/2)e⁻ᵗ − (3/5)e⁻²ᵗ + (1/10)cos t + (3/10)sin t 与手算一致，控制台没有报错。

- Legendre（l = 2）：x₁ = 1 − 3t² 被证明是多项式，数值解在奇点 t = ±1 处停下，部分和在 |t| < 1 外发散。把 l 拖到 3：推导立即变成 x₂ = t − (5/3)t³ 是多项式、x₁ 是无穷级数（这正是「拖动数字看方程怎么变」）。
- 受迫阻尼振子：u_h（虚线）衰减、u_p（点线）留下，核对偏差 3.6·10⁻¹¹；把 b 拖到 0：判别式变成 −16、根 ±2i、「无阻尼」，稳态那句自动消失。
- 375 px 手机宽度：没有横向溢出，推导里的平移说明「(n = k − 1)」不再从中间断行。

最要紧的几类，都已修复，每条都有手算推导的回归测试：

- **公开端点的代价**：链接在服务器上解码时曾跑精确运算（35 个字符的链接要 9 秒，长的要几分钟），现在只做静态检查。解的公式的精确运算和浮点核对、gcd 的单步、巨大系数的第一次转换都接上了预算（MCP 的 `solution_formula` 原来最长 148 秒才返回）。
- **保证不能说过头**：
  - 数值求出的奇点带被证明的包含半径。病态多项式原来报出的收敛半径比真值大 13.7 倍，甚至 10¹¹⁸ 倍。
  - 区间一律向下舍入。
  - 距离用精确对数计算：10⁴⁰⁰ 处的奇点不再被当成「没有奇点」，t₀ 极靠近 √2 时距离不再是 0。
- **核对的诚实**：
  - 正确的公式不再被判「未通过」：被初值压住的增长模态、很小的解。
  - 参考积分提前停下时，只声称实际比较过的范围。
  - 公式各项严重相消时说明无法比较，图改画数值解。
- **文字**：
  - 齐次方程不再提 xₚ；共振附近的不同指数不会打成同一个数。
  - 四舍五入的值不会像精确整数。
  - 学生的参数名不会和工具引入的字母冲突。
  - 结果里不再出现和表单冲突的 t₀。
