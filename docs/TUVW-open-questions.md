# TUVW 轮遗留问题（2026-09-18）

没有被 `it.fails()` 标记的新测试，没有改过任何容差，内核常数一个没动。下面是需要你或教授拿主意的事，按「课上最可能撞到」排序。

1. **慢机器上分类可能不跟手。** 拖动时「每个值都重算 features」的条件是上一次计算 ≤ 25 ms（冷启动前 3 次放宽到 150 ms）。这些数是在这台开发机上量的（阻尼振子 12 ms）。如果教授投屏用的笔记本慢一倍以上，阻尼振子也可能落进防抖：拖动时分类不变、停手 0.25 秒后才更新（会显示「Computing…」，不会错，只是不连续）。真遇到的话把 `FEATURE_SYNC_BUDGET_MS` 调大即可（它在 `lib/feature-schedule.ts`，不是内核常数）。需要一次真实课堂反馈。

2. **性能数字是脚本量的，不是人手拖的。** 内置浏览器窗口在后台时截图会超时，所以 U.3 的拖动是用脚本逐值派发 input 事件、读 DOM 完成的（生产构建：131 个值，中位 33.5 ms / 值）。真人拖动的事件密度不同（60 Hz 指针事件会被 React 合并），体感应该更好，但我没法替你确认。验证清单第 3 步请亲手拖一次。

3. **简报里 U.4 的一句话差了一个因子 2。** 「拍频包络周期是 2π/|w−g|，g = 1.2 时约 63」：解是 2.27·sin(0.1t)·sin(1.1t)，包络函数 sin((g−1)t/2) 的周期是 **4π/|g−1| = 62.8**，而拍（振幅 |包络|）每 **2π/|g−1| = 31.4** 重复一次。数字 63 对应的是前者。预设的 t 范围取 0..70，两种读法都盖得住；预设说明和帮助里我按数学写的，没有照抄那句话。

4. **零斜线找不到「不变号」的零点。** marching squares 靠符号翻转，`x' = (y − x²)²` 这类偶数重零点（函数值处处 ≥ 0）画不出零斜线，尽管那条抛物线上确实 x' = 0。这是方法的固有局限，不是 bug；帮助页目前没提。要不要在帮助里加一句「相切型的零点画不出来」？

5. **零斜线的残差护栏是一个新的启发式常数**（`NULLCLINE_RESIDUAL_FRACTION` = 0.25，在 `lib/phase-aids.ts`，内核之外）。它挡掉了 `1/x` 的极点和跳变处的假零斜线；代价是：一个在单个网格格子尺度上剧烈非线性的函数，真零点也可能被挡掉（80×80 的格子，正常课堂方程碰不到）。与 J 轮那些常数一样，没有课堂失败驱动就别调。

6. **异宿 / 同宿连接处两条分界线重叠。** 单摆的鞍点之间，稳定流形（实线）和不稳定流形（虚线）是同一条曲线，后画的盖住先画的，看上去是一条实线。数学上没错（它们确实重合），但图例里的「虚线」在这张图上找不到对应。可以接受，还是想换个画法（例如重叠处交替）？

7. **图例会挡住画面右上角。** 三个开关全开时图例有 6 行，盖住右上角约 190×100 像素。没有做避让。如果教授觉得碍事，可以挪到画布外（结果区上方），代价是导出的 PNG 里就没有图例了。

8. **讲课模式下英文标签 “domain edge, left” 有歧义。** 这是既有标签（`stabilityShort.edge_leave`，有测试锁着），意思是「解离开它」，但单独看像「左边」。以前它只出现在画布的小标签里，讲课模式把它放大成了结论行的主体（“Constant solution: domain edge, left”）。建议改成 “domain edge, solutions leave” / “domain edge, solutions approach”，但这会动到既有测试和画布标签，没敢顺手改。

9. **讲课模式隐藏了常数解的数值（y = 2）。** 我按「平衡点的数值坐标隐藏」类推处理的：讲课模式显示「常数解：稳定」，值在 ⓘ 里，画布上那条线还在。但对 logistic 这种课，「y = L」本身可能就是要讲的结论。如果教授想留着常数解的值，改 `lib/lecture.ts` 的 `constantSolutionLine` 一处即可。

10. **`ky` 这类两字母名字仍会被当成参数。** 会高亮并写明「被当作一个参数；想写乘积请写 k*y」，不是静默的，但图确实会先按 ky = 1 画出来。更保守的做法是拒绝所有含变量字母的两字母名字，代价是 `Ta`、`kx` 这类合法名字里真有一部分会被误伤。维持现状，等真实反馈。

11. **参数的取值上限是 ±1e6**（与链接里其他数字同一个界），参数最多 12 个，滑块最多 10000 步，曲线跨度上限 500 个时间单位。都是为了链接这个公开入口不被滥用而定的整数，没有数学含义；课堂上够用，超出时页面会用一句话说明。

12. **widget 里没有参数区、滑块、辅助线和讲课模式。** 这一轮只让 widget 的摘要带上参数取值（所以版本升到 `t-1`）。Claude 对话里要改参数只能让 Claude 重新调用工具。是否把滑块搬进 widget 留到下一轮决定（那会是一次真正的 widget 改动）。

13. **上一轮 open-questions #10 已关闭**（时间序列曲线跨度跟随 t 范围，上限 500）。其余 PQR / IJKL 的遗留问题原样保留，这一轮没有碰。
