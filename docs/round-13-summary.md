## 1. 做了什么

| 部分 | 内容 |
|---|---|
| 精确分析（lib/eigen） | 常系数线性系统（含常系数二阶方程的 (x, x') 相平面）：矩阵、平衡点、特征方程与判别式、特征值（有理数；无理数保留 √ 并附小数；复数 α ± βi）、整数特征向量 ξ（复数时 ξ = Re ξ + i·Im ξ，退化结点给出广义特征向量 η）、类型（可以精确判出中心）、通解。系数含 π 等近似值时说明，边界情况单独提醒 |
| 数值线性化 | 非线性系统：每个平衡点的雅可比矩阵、λ、特征向量或 Re ξ、Im ξ 与旋转方向、分类，开头说明为什么不是线性系统 |
| 没有可用特征值 | 范围内没有平衡点、方程含 t、一阶方程（「不适用」），各有一句说明 |
| 画面 | 线性系统整条特征直线（细线）；复特征值画 Re ξ、Im ξ 两根箭头和一段线性化轨线（开口；只有精确中心画闭合椭圆）；图例两项新条目 |
| 贴靠 | 12 像素以内：线性系统的特征直线、非线性鞍点的分界线（重新积分到精确的点；按「第一次减速」截断）、非线性结点的短线段（提示近似）；删除已保留曲线优先；Alt 不贴；触屏同样贴；画布短提示 + 图下一句完整说明 + 小圆圈；吸到的起点在链接里保留全部位数 |
| 预设 | 新的一章「线性系统与特征值」6 个 |
| widget z-2 | 同一个开关（工具的 showEigen 决定初始状态）、贴靠、紧凑面板 |
| MCP | analyze_system / analyze_second_order：线性系统的文字结果附精确分析；新参数 showEigen |
| 文字 | 帮助页、首页「能做什么」、更新说明（带「删除连接器重加」的提示）、README |

## 2. 实测

全部在 `next build` + `next start` 的生产构建上，用这个容器里的无头 Chromium：

- 直线解预设的系统 x' = x + y, y' = 4x + y：面板给出 λ² − 2λ − 3 = 0、λ = 3、−1、ξ₁ = (1, 2)、ξ₂ = (1, −2)、鞍点、通解；指针离 y = 2x 5 像素时贴靠，图下一句「已贴靠到特征方向 (1, 2)……」；按住 Alt 不贴；点击后链接里是 `traj=1.0099721712131435,2.019944342426287`（精确满足 y = 2x）。
- 二阶 x'' + 0.5x' + x = 0：λ = −1/4 ± (√15/4)i，ξ = (4, −1 + i√15)，顺时针的螺线和 Re ξ、Im ξ 箭头与向量场一致。
- 单摆 x' = y, y' = −sin x：(π, 0) 附近沿不稳定方向贴靠。**这里发现并修复了一个问题**：稳定分界线的长时间积分绕一圈回来与不稳定分界线重合，贴靠报错了分支；现在按「第一次减速」截断（见 decisions 第 6 节）。
- 非线性结点 x' = −x + y², y' = −2y：短线段内贴靠、提示近似；线段外不贴。
- 一阶方程：「不适用」一行。
- widget（`scripts/mock-host` 两源沙箱）：`showEigen` 打开开关，面板、贴靠都工作；中文二阶场景同样。
- `npm run smoke`（生产构建）：28/28，widget URI `z-2`。
- 性能：阻尼振子预设拖动 b，开关关时每步中位数 32 ms，开时 35 ms（p90 44 → 57 ms）。单摆开着开关整页 0.94 s 就绪（含为贴靠计算的分界线）。（评审修复后复查见第 4 节。）

## 3. 独立评审

两个没看过实现过程的评审各自从 tag `ab-review-1` 开始看：一个查数学与诚实性，一个查贴靠、工具、widget 与健壮性。两边确认的问题**全部修好**（提交前缀 `[AB-fix]`），每一条都有手算推导的测试。

数学与诚实性：

| 发现 | 修复 |
|---|---|
| 非线性系统的复特征值：Re 部分被单独缩放，Im 部分没有，印出来的向量不是特征向量（x'' + 22x' + 200 sin x 在原点应是 Re ξ = (1, −11)、Im ξ = (0, 8.888)） | 两部分用同一个因子，原样打印 |
| 记号和学生的符号冲突：特征向量叫 v，而 v = x' 是降阶用的；a、b、A、p、s 会和学生的参数同名（阻尼振子有 b，Lotka–Volterra 有 a、b、c、d） | 特征向量 ξ、广义特征向量 η（希腊字母不可能是参数名）；Re ξ、Im ξ；矩阵、单位矩阵、雅可比矩阵、通解常数的字母避开学生的参数（如有参数 A 就用 M，有 c 就用 C）；平衡点写成「令 x' = 0、y' = 0」；平衡点直线不用参数 s |
| 工具文字说「画面上的细直线」「鼠标贴靠」「级数面板」，而工具结果里没有画面，widget 默认关着开关，也没有级数面板 | 按显示位置分：工具文字不写画面和贴靠；级数面板那句只在网页 |
| 系数近似、迹恰好相消为 0 的系统（0.10000000000000000001x + y, −x − 0.1y）被判为「中心」并画闭合椭圆 | 近似系统里由非零项相消得到的精确 0 也单独提醒；类型写「对这个近似系统是中心，真实系统也可能是很弱的螺旋」，不再画闭合椭圆、不再写「确实是中心」 |
| 可疑：预算用完时什么也不说 | 说「超出了时间预算」，再给数值线性化 |
| 可疑：小数相消（λ₂ = 1.41421 − √2 ≈ 0） | 小的那个根用韦达定理 λ₂ = det / λ₁，现在是 ≈ 5.12·10⁻¹⁷ |
| 可疑：四舍五入后的数仍用「=」 | 四舍五入过的特征值后面一律附小数；说明改成「含这种小数的等式只在显示的位数内成立」 |
| 可疑：近似系数给出 15 位整数的特征向量 | 位数太多的向量按比例缩放成第一个分量为 1，用「≈」和小数写 |

贴靠、工具、widget 与健壮性：

| 发现 | 修复 |
|---|---|
| 一条 111 个字符的恶意链接（带 `aids=e`）让公网服务器每次请求算 5–7 秒（服务器渲染时就做精确读法，而且 500 ms 预算管不住单个大乘法） | 精确读法不在服务器渲染时做、方程含 t 时不做（本来就没有特征值）、widget 也有预算；lib/series 的乘法里加检查点。同一条链接现在 0.09 s |
| 工具文字说了不存在的画面和面板 | 同上（按显示位置分） |
| 字母和学生的参数同名 | 同上 |
| 贴靠状态过期：用键盘关掉开关、重置视图后，贴靠圈和提示还在；只按 Alt 不移动鼠标时，提示说贴靠了，点下去却没贴 | 贴靠目标一变就在指针所在处重新计算；重置视图时清掉；按下、松开 Alt 都立即重算 |
| 同宿轨道（x'' = x − x³）的分界线在经过中心 (1, 0) 时稍微减速，就被截断了一半，远端贴不上 | 截断要求「几乎停下」：速度不超过之前最快速度的 1/10（`BRANCH_SLOW_FRACTION`）。整个环都能贴，单摆仍然正确 |
| 可疑：触屏上提示「按住 Alt」 | 触屏改成「12 像素以内总会贴靠，想从线旁边出发先放大画面」 |
| 可疑：开着开关拖滑块时，每步都为贴靠重算分界线 | 拖动时不算，松手后再算 |
| 可疑：贴靠句子里四舍五入的 λ 和方向用「=」 | 只有精确印出的值用「=」，其他用「≈」 |

两个评审都确认没问题的部分：贴靠的起点精确在直线上、`precise` 标记在撤销/链接往返中保留、链接长度、删除已保留曲线优先于贴靠、`locate` 的耗时（最坏每帧 6 ms）、投影几何、widget 的开关重置、工具的输入边界、smoke 和更新说明。

没有修的一条（记入遗留问题）：abs(x) − abs(x) 这样恒为 0 的项被精确读法当成非线性。
