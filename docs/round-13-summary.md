## 1. 做了什么

| 部分 | 内容 |
|---|---|
| 精确分析（lib/eigen） | 常系数线性系统（含常系数二阶方程的 (x, x') 相平面）：矩阵 A、平衡点、特征方程与判别式、特征值（有理数；无理数保留 √ 并附小数；复数 α ± βi）、整数特征向量（复数时 v = a + b·i，退化结点给出广义特征向量）、类型（可以精确判出中心）、通解。系数含 π 等近似值时说明，边界情况单独提醒 |
| 数值线性化 | 非线性系统：每个平衡点的 J、λ、特征向量或 a、b 与旋转方向、分类，开头说明为什么不是线性系统 |

| 画面 | 线性系统整条特征直线（细线）；复特征值画 a、b 两根箭头和一段线性化轨线（开口；只有精确中心画闭合椭圆）；图例两项新条目 |

| widget z-2 | 同一个开关（工具的 showEigen 决定初始状态）、贴靠、紧凑面板 |
| MCP | analyze_system / analyze_second_order：线性系统的文字结果附精确分析；新参数 showEigen |

## 2. 实测

全部在 `next build` + `next start` 的生产构建上，用这个容器里的无头 Chromium：

- 直线解预设的系统 x' = x + y, y' = 4x + y：面板给出 λ² − 2λ − 3 = 0、λ = 3、−1、v = (1, 2)、(1, −2)、鞍点、通解；指针离 y = 2x 5 像素时贴靠，图下一句「已贴靠到特征方向 (1, 2)……」；按住 Alt 不贴；点击后链接里是 `traj=1.0099721712131435,2.019944342426287`（精确满足 y = 2x）。
- 二阶 x'' + 0.5x' + x = 0：λ = −1/4 ± (√15/4)i，v = (4, −1 + i√15)，顺时针的螺线和 a、b 箭头与向量场一致。
- 单摆 x' = y, y' = −sin x：(π, 0) 附近沿不稳定方向贴靠。**这里发现并修复了一个问题**：稳定分界线的长时间积分绕一圈回来与不稳定分界线重合，贴靠报错了分支；现在按「第一次减速」截断（见 decisions 第 6 节）。
- 非线性结点 x' = −x + y², y' = −2y：短线段内贴靠、提示近似；线段外不贴。
- 一阶方程：「不适用」一行。
- widget（`scripts/mock-host` 两源沙箱）：`showEigen` 打开开关，面板、贴靠都工作；中文二阶场景同样。
- `npm run smoke`（生产构建）：28/28，widget URI `z-2`。
- 性能：阻尼振子预设拖动 b，开关关时每步中位数 32 ms，开时 35 ms（p90 44 → 57 ms）。单摆开着开关整页 0.94 s 就绪（含为贴靠计算的分界线）。
