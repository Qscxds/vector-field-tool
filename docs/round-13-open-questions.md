# 第 13 轮遗留问题（2026-11-05）

> 第 13 轮的交付物（代号 AB；提交前缀 `[AB]`）。轮次对照表：[ROUNDS.md](ROUNDS.md)。

`lib/core` 一个字没动，没有改过任何既有容差，没有新的 `it.fails()`。按「课上最可能撞到」排序。

1. **Alt 键在 Windows 的 Firefox 上会打开菜单栏**（松开 Alt 时）。按约定用 Alt 暂时不贴靠；如果课上觉得别扭，可以改成 Shift，或者 Alt 和 Shift 都行。
2. **分界线的「画法」没有截断。** 贴靠只用分支的前一段（到第一次减速为止，见 decisions 第 6 节），但「鞍点的分界线」开关画出的仍是第 V 轮的整条长时间积分曲线，它在到达下一个平衡点后可能沿别的分支继续走（单摆上一条稳定分界线会绕一圈回来）。图上看起来就是两条重合的线，不影响结论，但严格说后半段已经不是那条分界线了。要不要把画法也截断，请看一节课再定。
3. **分界线截断规则是新的经验规则**（速度的第一个严格局部极小、且不超过此前最快速度的 1/10，`BRANCH_SLOW_FRACTION`；评审后从「第一次减速」改来，因为同宿环经过中心时的小幅减速曾把它截断一半），在 lib/core 之外，只决定贴靠范围。在螺旋汇附近，分支每转一圈速度都有起伏，深的那几圈之后就不能贴；一个很慢但不是平衡点的区域也会让它提前截断。宁可少贴，不会贴错。
4. **非线性结点的强方向**可以像分界线一样算出真正的不变曲线（逆时间积分强稳定流形），目前只在画出的短线段上近似贴靠。弱方向没有唯一的不变曲线，短线段是合理的。
5. **平衡点在范围外的线性系统**：面板照样给出精确的平衡点和特征值，平衡点列表（数值，按范围找）却是空的；特征直线只要穿过画面就画。可以在面板里加一句「平衡点在当前范围之外」。
6. **det A = 0 且没有平衡点**（例如 x' = 1, y' = x）时不写通解（解里有 t 的多项式项）；二阶的 x'' = 常数 同理。课本里这类题少见。
7. **近似系统的边界提醒**（`NEAR_ZERO_FRACTION` 1e-12）是显示上的选择；它只在系数含 π、e、函数值等时出现。
8. **讲课模式不隐藏面板里的数字**（和级数面板一致）。如果投屏时觉得太长，可以在讲课模式下只留特征值和类型两步。
9. **widget 的开关不进链接**：widget 没有链接状态；它跟随工具的 `showEigen`，学生在 widget 里改的开关不会保存。
10. **MCP 文字结果变长了**：线性系统的 analyze_system / analyze_second_order 结果末尾总有十几行精确分析。如果实际对话里 Claude 转述得太啰嗦，可以改成只有 `showEigen` 时才附上。
11. **重新积分得到的分界线点**和画出的折线不是同一组积分步（积分区间不同，最大步长也不同），差别在积分器的误差以内，屏幕上看不出来。
12. **贴靠后的鞍点稳定方向解**：起点精确在直线上（线性系统）时，积分到鞍点附近会因「到达平衡点」而停；非线性分界线上的起点本来就不在流形上（偏差来自分界线起点的线性化偏移和积分误差），所以靠近鞍点后会沿某一侧离开。图下那句话说了这一点。
13. **数值方向的显示**按「第一个分量为 1」缩放；第一个分量不到第二个的十分之一时改为「第二个分量为 1」。这只是显示，(0.05, 1) 和 (1, 20) 是同一个方向。复特征值的 Re ξ、Im ξ 不这样各自缩放（评审发现过这个错误），两者用同一个因子。
14. **近似标记是整个式子的，不是每个系数的。** 所以 πx + 20y, −x − πy 这种 π 与 −π 相消、真实系统其实就是中心的情况，也会被提醒「迹由近似系数相消得到」（提醒的话写了这种情况也可能成立）。要精确区分，需要 lib/series 的读法给每个系数单独标记。二阶方程的系数内部相消（例如 (0.1000000000000000000001 − 0.1)x'）目前不会被提醒。
15. **abs(x) − abs(x) 这类恒为 0 的项**被精确读法当成非线性（数学评审的可疑项，未修）：读法逐项看，abs(x) 不是 x 的线性项。课上不太会这样写。
16. **触屏上没法暂时不贴靠**：没有 Alt 键，离线 12 像素以内的点按总会贴靠；句子里提示先放大画面。如果课上需要，可以加一个「暂时不贴靠」的按钮。
17. **面板在网页上要等第一次客户端渲染**（为了不让服务器做精确计算），打开带 `aids=e` 的链接时，面板比画面晚出现一瞬间。
