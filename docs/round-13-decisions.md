## 3. 精确分析

- tr、det、判别式 (a − d)² + 4bc 全部有理数精确运算；类型由 det、判别式、tr 的**精确符号**决定（线性系统可以精确地判出中心）。
- 数域 Q(√disc)：√disc = scale·√m，m 去掉 10000 以内素数的平方因子（`SQUARE_FREE_LIMIT`；更大的平方因子留在根号里，仍然精确，只是没化到最简）；复数时 √disc = i·scale·√m。每个数写成 r + s√m。
- 特征向量：b ≠ 0 时 ξ± = (2b, (d − a) ± √disc)，否则 (λ − d, c)，对角矩阵用 e₁、e₂；再缩放成**分量为整数、互素、第一个非零分量为正**。复数时 ξ 是 α + iβ（β > 0）的特征向量，写成 Re ξ + i·Im ξ。
- 退化结点：广义特征向量 η 解 (A − λI)η = ξ，精确验算后才给出。
- 平衡点：det ≠ 0 时解 A·(x, y) = −b（文字写成「令 x' = 0、y' = 0」）；det = 0 时分成一整条直线、整个平面、没有平衡点三种。
- 通解按学生的记号写：平面 (x(t), y(t))，二阶 x(t)；有理特征值写出具体指数，无理和复数写成 λ₁、ξ₁、α、β、Re ξ、Im ξ 的符号形式并说明「取上面的值」；平衡点不在原点时加上平移。没有平衡点时不写通解（解里有 t 的多项式项）。
- **近似系统的边界**：`approximate` 时，tr、det、判别式中**不为 0 但在矩阵自身大小的 10⁻¹² 以内**的会单独提醒（`NEAR_ZERO_FRACTION`）。这是显示上的选择，不改任何结论：结论仍然是对近似系统精确的，只是说明 16 位小数的取舍可能改变类型。π·y、−π·x 这种两个系数是同一个 double 的情况，迹恰好为 0，不提醒。

## 4. 数值线性化（非线性系统）

- 不重新判断任何东西：实特征方向来自第 V 轮的 `eigenDirections`（由内核自己的分类决定），复数时 ξ = (2b, (d − a) + i√(−disc))，第一个分量缩放成 1（Re ξ 和 Im ξ 用同一个因子）。
- 面板每个平衡点写雅可比矩阵、λ、特征向量（或 Re ξ、Im ξ 与旋转方向）、分类；重根在误差内仍带 repeatedRoot 的短提示。开头一句说明为什么不是线性系统（指出学生写的那一项）。

## 5. 画面

- 线性系统：整条特征直线用细线画出（稳定实线、不稳定虚线），平衡点处的粗短线和箭头照旧；数据来自精确分析，不来自内核的数值雅可比。平衡点在范围外时，只要直线穿过画面也画。
- 复特征值：从平衡点画 Re ξ、Im ξ 两根细箭头（就标 Re ξ、Im ξ），再画线性化流 e^(αt)(Re ξ cos βt − Im ξ sin βt) 的一段（点线，末端箭头表示时间方向，所以旋转方向就是流的方向）。只画最多 3/4 圈（`ARC_OPEN_ANGLE`），半径变化最多 4 倍（`ARC_MAX_GROWTH`，强螺旋就画短一点，不扭曲）；**只有线性系统的精确中心画闭合椭圆**，数值上的「中心或弱螺旋」永远是开口的弧。
- 图例新增「直线解（线性系统）」和「Re ξ、Im ξ 与旋转方向」。
- 矩阵用方括号显示（新增 notation 的 matrix 段；纯文本写成 [[a, b], [c, d]]）。最初用的是两条竖线，看起来像行列式，已改。

## 6. 贴靠

- 规则（`lib/eigen/geometry.ts snapPoint`）：屏幕距离 12 像素以内（`SNAP_THRESHOLD_PX`，比删除已保留曲线的 8 像素稍大；删除优先）。只在开关打开时；按住 Alt 不贴；触屏的点按预览和长按保留同样贴。
  - 线性系统：整条特征直线，吸到垂足（世界坐标里精确在线上）。
  - 非线性鞍点：分界线。分界线没显示时只在画出的短线段范围内（离鞍点的屏幕距离不超过短线段半长）；显示时整条分界线都可以贴。吸到的点**重新积分**：从分界线自己的起点积分到最近点的时刻，得到积分器自己的曲线上的点，而不是折线上的插值点。
  - 非线性结点：只在画出的短线段上，提示写「近似」。
  - 星形结点、螺旋、中心、非双曲：不贴。
- **分界线截断（浏览器实测时发现）**：分界线是长时间积分。单摆 (π, 0) 的稳定分界线逆时间积分，绕着 (2π, 0) 转一圈后又沿**不稳定**分界线回到鞍点附近，于是同一个位置两条分界线并列，贴靠时报成了「稳定分界线」。真正的分界线到下一个平衡点就结束（需要无穷长时间），数值曲线之后离开流形、沿别的分支走。所以贴靠只用分支的前一段：到它**第一次减速**（相邻积分点之间的弦长除以时间步，在升高之后出现的第一个严格局部极小）为止，这正是它接近下一个平衡点的地方，不管那个平衡点在不在列表里。冲进汇点的分支一直减速，整条保留。这只影响贴靠，分界线的画法（第 V 轮）不变。这是贴靠用的新经验规则，在 lib/core 之外，记入遗留问题。
- 提示：画布上几个字（「直线解 λ = 3」「稳定分界线」「特征方向附近（近似）」），图下方一句完整的话（吸到了什么、从这里出发的解怎么走、按住 Alt 可以不贴）。图上在吸到的点画一个小圆圈。
- 链接：吸到的起点标记 `precise`，`traj` 里写出全部位数（double 的最短往返小数），普通点击仍是 6 位有效数字。否则重新打开链接时起点会偏离直线，鞍点稳定方向上的解会在鞍点附近明显拐走。读链接时位数超过 6 位的起点重新标记 `precise`，所以再写回去时不变。

## 12. 独立评审之后的决定（修复 `[AB-fix]`）

两个评审的发现和修复列在 summary 第 3 节。这里只记下修复时做的选择。

- **字母**：特征向量 ξ、广义特征向量 η（Boyce 的写法；希腊字母过不了参数名的规则 `^[A-Za-z_][A-Za-z0-9_]*$`，永远不会和学生的参数同名）。矩阵、单位矩阵、雅可比矩阵、通解常数从几个候选里取第一个不是学生参数名的（`eigenLetters`：矩阵 A → M → B → K；单位矩阵 I → E，E 是解析器的保留字；雅可比矩阵 J → M → K；常数 c → C → k → K），和第 12 轮 `seriesLetters` 同一个做法。v 留给降阶的 v = x'。
- **显示位置**（`surface`）：网页全部说明；widget 有画面和指针，但没有级数面板；工具文字没有画面、没有指针，所以不写画了什么、怎么贴靠。工具结果时 widget 的开关默认是关的，这是主要原因。
- **四舍五入造成的中心**：近似系统里，tr、det、判别式**恰好为 0 但由非零项相消得到**时也算边界（`exactZero`）。迹只在决定类型时才算（复特征值，或 det = 0）：鞍点的迹为 0 不影响类型。这样 πx + 20y, −x − πy 这种 π 与 −π 相消的系统也会被提醒；提醒的话专门写了「只有真实系统里这些项也恰好相消（例如 π 与 −π）时才成立」，对这种情况也是对的。没有做逐个系数的近似标记（lib/series 的读法只给整个式子一个标记），见遗留问题。
- **小数**：两个不同实根时，两部分同号的那个直接算，另一个用 λ₁λ₂ = det（`eigenvalueNumbers`），图上的特征值和贴靠提示也用它。四舍五入过的特征值后面一律附小数。分量位数超过 9 位（分子分母合计，`HUGE_VECTOR_DIGITS`）的向量缩放成第一个分量为 1 写小数；广义特征向量和特征向量用同一个因子（(A − λI)η = ξ 要成立），复数的实部、虚部也用同一个因子；这时通解写成符号形式。
- **不在服务器上算**：网页的精确读法等到客户端（`useSyncExternalStore` 的 hydration 标记，不多一次服务器渲染，也不用 effect 里 setState），所以面板在第一次客户端渲染后才出现；方程含 t 时不读（只会得到「含 t」，而恶意式子的代价正来自 t）；读法超时就说超时。lib/series 的 `qpMul` 多了一个可选检查点参数，结果完全不变，只是预算能在一个大乘法中途停下。
- **分界线截断**：第 6 节的「第一次减速」改成「第一次几乎停下」：局部极小的速度不超过此前最快速度的 1/10（`BRANCH_SLOW_FRACTION`）。接近平衡点时速度趋于 0，经过中心附近只是小幅减速。同宿环现在整条可贴（两条分支都覆盖同一个环，贴到哪一条都对）。
- **贴靠状态**：贴靠目标（开关、平衡点、线性系统）一变，就在指针停留处重新计算一次；视图重置时清掉；监听 Alt 的按下和松开。触屏的句子说「12 像素以内总会贴靠，想从线旁边出发先放大画面」；拖滑块时不为贴靠算分界线。
- **「=」与「≈」**：贴靠提示里只有能原样印出的 λ 和方向用「=」（容许 double 最后几位的误差，斜率 2 算出来是 2.0000000000000004），否则用「≈」。
